# Security Policy

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting:
the **Security** tab → **Report a vulnerability**. Do not open public
issues for security reports.

We aim to acknowledge reports within 3 business days.

## Scope

This repository holds the generated SDK clients for the FEVER Retrieval
appliance API and the workflows that build them. Findings in the appliance
or API itself are welcome through the same channel.

## Supported versions

Only the latest release tag is supported. Fixes ship as new releases; there
are no backport branches.
